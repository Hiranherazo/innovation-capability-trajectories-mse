# NetLogo Model
 
This folder contains the Agent-Based Simulation (ABS) model developed for the study:
 
"Innovation Capability Trajectories in Micro and Small Enterprises: A Microfoundational Explanation Based on Individual Innovation Capability Development"
 
## Model Purpose
 
The model was developed to investigate how organizational innovation capability emerges within Micro and Small Enterprises (MSEs) through the interaction of:
 
- Organizational Support
- Governance
- Innovation Culture Contagion
- Potential Well-Being (PWB)
- Innovation Profile (IP)
- Time Allocation Decisions
- Individual Innovation Capability (Ladvantage)
 
## Platform
 
- Software: NetLogo
- Modeling approach: Agent-Based Simulation (ABS)
 
## Main Outputs
 
The model generates information related to:
 
- Individual innovation capability (Ladvantage)
- Organizational innovation capability
- Innovation capability trajectories
- Worker behavior and effort-allocation decisions
