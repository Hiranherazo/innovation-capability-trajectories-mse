# R Analysis
 
This folder contains the statistical analysis materials used in the study:
 
"Innovation Capability Trajectories in Micro and Small Enterprises: A Microfoundational Explanation Based on Individual Innovation Capability Development"
 
## Purpose
 
The files in this folder were used to analyze simulation outputs generated through NetLogo BehavioralSpace experiments.
 
The analyses support the identification and interpretation of:
 
- Innovation capability trajectories
- Longitudinal patterns of capability development
- Descriptive statistics
- Clustering procedures
 
## Contents
 
### analysis.qmd
 
Quarto document containing the analytical workflow used to process and interpret simulation outputs.
 
### clustering.R
 
R script used to perform clustering analyses and identify the innovation capability trajectories reported in the study.
 
## Main Outputs
 
The analyses contributed to the identification of three recurrent innovation capability trajectories:
 
- Accumulation
- Sustaining
- Erosion
 
These trajectories constitute the principal empirical findings reported in the associated manuscript.
 
## Software Requirements
 
To execute the analyses, the following software may be required:
 
- R
- Quarto
 
## Reproducibility
 
The files included in this folder provide the analytical procedures used to interpret simulation results and support the reproducibility of the study.
